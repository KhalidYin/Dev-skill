# TFLs-Shell

将用户材料和已确认的展示要求整理为受控 shell 推荐与可审阅交付。依赖上游 `tflshell` 生成器；参考资产随本 Skill 携带。读取 [运行说明](references/integration.md) 核对依赖，读取 [输入和交付契约](references/request-contract.md) 准备执行配置。

## 理解任务与补充信息

- 区分只推荐、通用模板、研究特定交付。只推荐使用 `--mode recommend`，不写业务文件。
- 先读取材料及当前对话，提取分期、领域、终点、分析集、治疗组、时间点和交付范围，保留来源位置。材料不可读时先完成文本提取；不要把读取失败解释为无研究限制。
- Agent 解释材料，将明确决定写入结构化 `study` 和选定 `shell_ids`。内置中英关键词只辅助推荐，不能代替全文理解。不得把敏感原文用于网络检索。
- 复用已有答案，只集中询问影响当前输出的未决项，不重复问询。
- 研究特定交付缺少分期、领域、终点、分析集、治疗组、时间点或存在冲突时，暂停受影响生成并说明缺口。用户明确只要通用模板时，使用 `--generic-template` 并保留占位符。

## 语言和格式偏好

首次生成前，集中核对语言（英文、中文、双语）、Sponsor 模板、纸张和方向、字体、治疗组表头及顺序、编号和交付物版本。已明确的要求直接采用；只对确实影响输出且无法推断的未决选择提问。

- 用户授权采用默认时，说明默认：英文、Letter 横向、0.75 英寸边距、Times New Roman、标准间距、交付版本 `0.1-draft`。通用组名为占位符。
- 治疗组、分析集和时间点属于研究实质要求，不能用展示默认值代替。根据材料用 `shell_overrides` 设置各 shell 的标题、分析集和时间点说明。
- Sponsor 模板先检查并形成字段/样式映射。当前脚本不自动导入任意模板；未完成映射的 `sponsor_template` 会返回缺口。明确报告超出支持范围的要求，不能问询后静默忽略。
- 中文/双语由 agent 准备并复核精确翻译映射。脚本返回 `needs_localization` 时，agent 补全字符串映射后重试，不把内部翻译任务转交用户。不把中英混杂半成品称为中文交付。
- 非英文图内文字尚需单独适配；当前使用 `--no-figures` 输出占位框，或明确报告本地化缺口。

## 推荐和生成

1. 参照 `package_assets/catalog_subset.json` 和 Product catalog 推荐基础包、可选扩展、排除项和理由，覆盖 CSR 14.1、14.2、14.3、14.4、16.2。
2. 核对 PFS/OS 等终点已纳入疗效范围；剂量递增、特殊设计及非标准终点人工复核。用 `shell_ids` 表达实际选择，不把默认候选直接当作研究定稿。
3. Agent 准备 JSON 配置，用户无需手写。字段、命令和返回状态见 [输入和交付契约](references/request-contract.md)。`needs_information` 时先补齐未决项。
4. 生成器版本、模板契约版本和交付物版本分别记录。通过配置或 `--document-version` 设置交付版本，同步文件名、封面、页眉和属性；禁止仅改文件名。
5. `group_labels` 按顺序调整通用治疗列，支持单臂和多个组，保留 Overall/HR 等独立分析列；`header_labels` 修改标签。保留 N 和统计量占位符，不猜测真实结果。
6. 使用新目录或新交付版本。脚本先暂存、按配置检查，再发布，拒绝覆盖已有同名文件。

## 标题、验证与交付

- 每个 shell 只保留一个包含编号和名称的 Heading 4，目录引用该标题。信息块保留 Sponsor、Protocol、研究名称、分析集，不重复输出编号/名称。
- 使用生成时输出的 `delivery-contract_v*.json` 重新验证，支持研究子集及定制配置。无契约的旧检查器只用于原始 Product 基线。
- 核对 ID 与标题、组别/分析列表头和顺序、分析集、Protocol 页眉、版本、页面/字体和标题唯一性。对 Office 文件检查实际视觉布局；对译文复核术语和含义。
- `passed` 是机械检查结论，不代表已完成临床审核。模拟图和占位值不能当作研究结果。
- 返回文件、研究范围、语言/格式/版本摘要、验证结果及剩余问题，明确实质假设，不只返回路径。

## 维护

- `docs/` 和 `package_assets/` 保留上游原始基线；本地定制以 `references/request-contract.md` 和随交付输出的契约为准。
- 复用 Product 生成器，在 Skill 层完成输入关卡和交付适配；不复制整个 Product 或另建统计生成器。
- 安装使用本项目 `scripts/install.ps1 -SkillName tfls-shell`。修改后执行回归、全量技能校验、注册和索引更新。
