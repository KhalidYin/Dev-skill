# SOP 契约

## 1. 输出

Product 对齐的 SOP 输出为：

- `TFL_Shell_SOP_v<version>.docx`

SOP 是受控使用文档，不是非正式 readme。

## 2. Header Block

SOP 必须包含 header table，其中包括：

- `SOP No.`
- `Version`
- `Effective Date`
- `Department`
- `Classification`

`Classification` must be `CONFIDENTIAL`.

## 3. 必需 Scope

SOP scope 必须包含：

`14.1, 14.2, 14.3, 14.4, and 16.2`

## 4. 必需结构

SOP 必须包含以下 major headings：

- `1.  PURPOSE AND SCOPE`
- `2.  DEFINITIONS AND ABBREVIATIONS`
- `3.  RESPONSIBILITIES`
- `4.  PROCEDURE`
- `5.  REFERENCES`
- `6.  APPENDICES`

SOP 必须包含 Appendix headings：

- `Appendix A  Companion Workbook`
- `Appendix B  Shell Output Notes`

## 5. 治理语言

SOP 必须说明：

- shell-first use
- governed deliverables
- cross-output alignment
- version control and change management
- generation, catalog validation, and regression tests as quality gates
