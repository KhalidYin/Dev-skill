# Review Protocol 章节和分析审阅深化

## 目标

按用户确认的顺序审阅统计章节完整性、逐项分析和跨章节一致性，交付精简且可扩展的 Excel。

## 背景与范围

用户确认判型后先查统计章节完整性，再审查语句歧义、预设充分性和方法合理性。保留作者可执行的批注、判定理由和证据。默认固定四页，详细证据与对照按需追加一页。
